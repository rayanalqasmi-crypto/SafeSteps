
# 🛡️ SafeSteps

Learn Safely. Act Confidently. Stay Prepared.
SafeSteps is an accessible, bilingual educational web platform designed to help people learn how to respond safely to emergencies through interactive and inclusive learning experiences.

🎯 Project Objectives
- Raise awareness of safety and emergencies.
- Make safety education accessible to diverse users.
- Build confidence through interactive simulations.
- Support independent learning at an individual pace.

✨ Key Features
- Arabic and English language support.
- RTL and LTR interface support.
- Six interactive emergency scenarios.
- 19 educational illustrations.
- Interactive simulations and quizzes.
- Immediate answer feedback.
- Learning progress and achievement tracking.
- Responsive design for desktop, tablet, and mobile.

📚 Learning Modes
SafeSteps provides four learning modes:

- Visual Learning
- Reading Mode
- Audio Learning
- Simplified Learning

♿ Accessibility Features
- Adjustable text size from 100% to 200%.
- High contrast mode.
- Reduced motion mode.
- Simplified interface.
- Keyboard navigation.
- Screen reader support features.
- Text-to-speech functionality.
- Skip-to-content navigation.
- Responsive navigation for enlarged text.

🚨 Emergency Scenarios
1. Fires
2. First Aid
3. Injuries and Bleeding
4. Road Accidents
5. Natural Hazards
6. Choking

👥 Target Audience
- Children and young learners.
- Older adults.
- People with disabilities.
- Individuals with different learning preferences.
- Anyone interested in safety education.

🛠️ Technologies Used
- React
- TypeScript
- Vite
- CSS
- Lucide React
- Web Speech API
- Local Storage

🚀 Getting Started
Install dependencies:

    npm install

Start the development server:

    npm run dev

Build the project:

    npm run build

🌐 Live Demo
https://safe-steps-six.vercel.app/

💚 Project Vision
Safety education should be accessible to everyone, regardless of age, ability, language, or learning preference.
SafeSteps aims to create an inclusive digital learning experience that empowers users with essential safety knowledge.

⚠️ Disclaimer
SafeSteps is intended for educational and awareness purposes only. It does not replace professional emergency assistance or certified first-aid training.
